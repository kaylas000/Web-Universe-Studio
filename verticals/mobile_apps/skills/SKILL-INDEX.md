# SKILL-INDEX — приёмы студии «Студия мобильных приложений»

Реестр приёмов вертикали `mobile_apps` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `screen-composer` | Собирает экран: манифест, модуль с состоянием, доступная разметка. | Описать манифест → Собрать состояние экрана → Отрисовать разметку → Добавить подписи доступности → Проверить анти-слоп |
| `a11y-pass` | Приём студии «Студия мобильных приложений»: a11y-pass. | — |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
