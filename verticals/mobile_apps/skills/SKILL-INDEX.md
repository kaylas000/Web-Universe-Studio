# SKILL-INDEX — приёмы студии «Студия мобильных приложений»

Реестр приёмов вертикали `mobile_apps` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `screen-composer` | Собирает экран: манифест, модуль с состоянием, доступная разметка. | Разобрать бриф → Описать манифест → Собрать состояние экрана → Отрисовать разметку → Добавить подписи доступности → Приёмка |
| `a11y-pass` | Аудит доступности: тач-таргеты ≥44/48, подписи, контраст, фокус. | Пройти по элементам → Проверить тач-таргеты → Проверить подписи → Проверить фокус → Прогнать lint-slop |
| `offline-queue` | Офлайн-кэш и очередь запросов, retry и ошибки (К-07, К-17). | NetInfo listener → Кэш в локальном хранилище → Очередь запросов → Retry → UI ошибок → Квота Q-06 |
| `store-release` | Готовность к сторам: иконка, скриншоты, описание (К-20). | Иконка 1024×1024 → Скриншоты 6.5"+5.5" → Описание → Сверка экранов → Квота Q-01 |
| `i18n-pass` | Локализация en+ru через i18n, без хардкода строк (К-14, B-04). | Собрать строки → Сверить ключи en/ru → Плюралы и форматы → Переводы → lint-slop |
| `nav-deeplinks` | Нативные стеки и deep links (К-08, К-13). | Стек навигации → Схема приложения → Universal/app links → Обработка ссылки → Квота Q-05 |
| `usability-heuristics` | Эвристики NN/g: статус, выход, ошибки, распознавание, справка (К-23). | Карта 10 эвристик → Статус (NetInfo) → Стек (выход) → Retry → Подписи → Справка (i18n) → Отчёт heuristics_report.md |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
