# CONSTITUTION.md — закон студии «Студия мобильных приложений»

Полные статьи вертикали `mobile_apps` (§9 ТЗ). Проверка статьи — метод из ТЗ (графа «Проверка»):
детерминированный офлайн-набор `scripts/validate.mjs` (коды `V-xx`) реализует подмножество статей; остальное — приёмка человеком на G4 (REVIEW.md).

## Статьи

- **К-01. Гайдлайны платформы.** Соответствие гайдлайнам платформы: iOS — Apple HIG, Android — Material Design 3. *Проверка:* статический анализ + чек-лист гайдлайнов.
- **К-02. Safe Area.** Safe Area (notch / home indicator): SafeAreaView (RN) / SafeArea (Flutter) / .safeAreaInset (SwiftUI). *Проверка:* статический анализ.
- **К-03. Тач-таргеты.** Тач-таргеты: iOS ≥ 44×44 pt, Android ≥ 48×48 dp. *Проверка:* анализ стилей.
- **К-04. 4 состояния экрана.** Каждый экран имеет 4 состояния: Loading, Empty, Error, Success. *Проверка:* наличие компонентов.
- **К-05. Тёмная тема.** Поддержка тёмной темы (Appearance API / useColorScheme). *Проверка:* статический анализ.
- **К-06. FPS и запуск.** FPS ≥ 55 на mid-range, запуск < 2 c. *Проверка:* Flipper / Flutter DevTools.
- **К-07. Offline.** Offline-режим: кэш и очередь запросов. *Проверка:* NetInfo listener + локальное хранилище.
- **К-08. Нативные стеки.** Нативные стеки навигации (React Navigation / go_router / NavigationStack). *Проверка:* отсутствие кастомных стеков без анимаций.
- **К-09. Клавиатура.** Клавиатура не перекрывает поля ввода (KeyboardAvoidingView / Scaffold). *Проверка:* статический анализ.
- **К-10. Планшеты.** Адаптивный layout на планшетах (iPad / Android tablet). *Проверка:* скриншоты.
- **К-11. Accessibility.** Accessibility: accessibilityLabel / semanticLabel. *Проверка:* статический анализ + Accessibility Inspector.
- **К-12. Разрешения.** Разрешения запрашиваются в момент использования, а не на старте. *Проверка:* отсутствие запросов в componentDidMount/initState.
- **К-13. Deep links.** Обработка deep links (universal/app links). *Проверка:* Info.plist / AndroidManifest.xml.
- **К-14. Локализация.** Локализация минимум на 2 языка (en + ru) через i18n. *Проверка:* наличие i18next/intl/Localizable.strings.
- **К-15. Push.** Push-уведомления через FCM / APNs. *Проверка:* наличие onMessage-обработчика.
- **К-16. Стейт-менеджер.** Единый стейт-менеджер (Redux / Zustand / Riverpod / Bloc). *Проверка:* отсутствие prop drilling > 3 уровней.
- **К-17. Retry и ошибки.** Все API-вызовы имеют retry-логику и user-friendly сообщения об ошибках. *Проверка:* try-catch с UI-фидбеком.
- **К-18. 5+ разрешений.** Тестирование на 5+ разрешениях (iPhone SE…Android 600dp). *Проверка:* скриншоты Detox/Appium.
- **К-19. Биометрия.** Биометрия через нативные API (react-native-biometrics / local_auth). *Проверка:* статический анализ.
- **К-20. Готовность к сторам.** Готовность к сторам: иконка 1024×1024, скриншоты 6.5" + 5.5", описание. *Проверка:* наличие файлов в assets/.
- **К-21. Микрокопи.** Тексты без маркетинговых штампов; ошибка рядом со следующим шагом; кнопки называют действие, а не «нажмите сюда». *Проверка:* V-21 (скан locales/ru.json) + B-07…B-10 в lint-slop.
- **К-22. Контраст текста.** Контраст текста к фону — не ниже 4.5:1 (WCAG 2.1 AA) в светлой и тёмной темах. Таблица токенов — `app/theme.json` (пары `contrast`). *Проверка:* V-22 (kind `themeContrast`: каждая пара темы проходит порог; расчёт по WCAG 2.1).

**Гейты:** G1 Бриф/категория → G2 Архитектура/экраны → G3 Сборка/TS → G4 Устройства/сторы.
