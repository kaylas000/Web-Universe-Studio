# HEURISTICS.md — карта эвристик юзабилити NN/g (К-23)

Источник: Jakob Nielsen, «10 Usability Heuristics for User Interface Design»
(NN/g, ред. 2024) — `references/metadata/ref-14.yaml` (REF-14). Эвристики — это
каркас приёмки: качественные пункты проверяет артдиректор на G4, а проверяемое
ядро — детерминированный прокси-скан `V-23` в `scripts/validate.mjs`.

## Карта 10 эвристик → прокси артефакта

| # | Эвристика NN/g | Что значит для экрана | Где проверяется |
| --- | --- | --- | --- |
| H1 | Видимость системного статуса | Сеть и загрузка видны: offline-индикатор, статус состояния | **V-23**: `NetInfo`/`status:` в `app/src/App.mjs` (+ V-04 состояния) |
| H2 | Соответствие системы реальному миру | Язык пользователя, без жаргона и штампов | B-07 в `lint-slop` + V-21 (микрокопи locales) |
| H3 | Свобода и контроль | Нативный стек: назад/закрытие предсказуемы | **V-23**: `createNativeStackNavigator`/`go_router`/`NavigationStack` (+ V-08) |
| H4 | Консистентность и стандарты | Платформенные паттерны и компоненты | К-01 (гайдлайны), REF-02/REF-09 |
| H5 | Предотвращение ошибок | API-вызовы с retry; деструктивное подтверждается | **V-23**: `attempts`/`retry` (+ V-17) |
| H6 | Распознавание, а не припоминание | Подписи элементов для скринридера и глаза | **V-23**: `accessibilityLabel`/`semanticLabel` (+ V-11) |
| H7 | Гибкость и эффективность | Быстрый путь: биометрия по действию пользователя | V-19 (биометрия), К-12 (разрешения по месту) |
| H8 | Эстетика и минимализм | Один экран — одна задача, без декоративного шума | Квота Q-02/Q-04 + REF-08 |
| H9 | Помощь распознать, диагностировать и восстановиться после ошибки | Текст ошибки объясняет следующий шаг | V-17 (try-catch UI-фидбек) + B-09 |
| H10 | Справка и документация | Есть вход в справку, не мёртвый текст | **V-23**: `i18n.t("help")` + ключ `help` в locales |

## Как закрывать

1. `node scripts/validate.mjs projects/<имя>` — `V-23` обязан быть `OK` (5 прокси).
2. `node scripts/lint-slop.mjs projects/<имя>` — `чисто:` (B-04, B-07, B-09, B-10 закрывают H2/H9).
3. Возврат — точечная правка по коду из feedback (К-10), а не перезапуск экрана.

Приём, который закрепляет эту карту: `skills/usability-heuristics/`.
