# CONSTITUTION.md — закон студии «Студия данных»

Полные статьи вертикали `data_analytics` (§9 ТЗ). Проверка статьи — метод из ТЗ (графа «Проверка»):
детерминированный офлайн-набор `scripts/validate.mjs` (коды `V-xx`) реализует подмножество статей; остальное — приёмка человеком на G4 (REVIEW.md).

## Статьи

- **К-01. Синтаксис.** SQL/Python синтаксически валиден. *Проверка:* парсер SQL + `python -m py_compile`.
- **К-02. Без SELECT *.** Нет SELECT * в продакшн-запросах (перечисляй колонки). *Проверка:* regex-линтер.
- **К-03. JOIN вместо подзапросов.** JOIN вместо коррелированных подзапросов там, где это возможно. *Проверка:* анализ плана/эвристика.
- **К-04. EXPLAIN ANALYZE.** Выполнен EXPLAIN ANALYZE; нет Seq Scan по большим таблицам. *Проверка:* парсер плана EXPLAIN ANALYZE (статический анализ).
- **К-05. Обработка ошибок.** Обработаны ошибки и пустой результат. *Проверка:* наличие try/except/try/catch.
- **К-06. Документация.** Документация: docstring/комментарии с назначением. *Проверка:* AST-линтер.
- **К-07. Воспроизводимость.** Воспроизводимость: параметризация, фиксированный seed, pinned версии. *Проверка:* чек-лист.
- **К-08. Параметризация.** Параметризация против SQL-инъекций (нет f-string в запросах). *Проверка:* regex-линтер.
- **К-09. Идемпотентность.** Идемпотентность ETL-скриптов (повторный запуск не дублирует данные). *Проверка:* анализ ключей/upsert.
- **К-10. Валидация входа.** Входные данные валидируются по схеме. *Проверка:* schema-валидатор.
- **К-11. Метрики качества.** Метрики качества данных: nulls, дубликаты, типы. *Проверка:* профилировщик.
- **К-12. Контроль стоимости.** Контроль стоимости/сканирования: партиции, LIMIT, фильтры. *Проверка:* оценка плана.
- **К-13. Бюджет времени.** Время выполнения укладывается в бюджет. *Проверка:* замер времени.
- **К-14. PII.** PII маскируется/хешируется. *Проверка:* regex по чувствительным полям.
- **К-15. Воспроизводимость результата.** Результаты воспроизводимы на тестовом наборе. *Проверка:* повторный прогон на тестовом наборе.

**Гейты:** G1 Бриф/источники данных → G2 Схема/план → G3 Запрос/скрипт → G4 Воспроизводимость.
