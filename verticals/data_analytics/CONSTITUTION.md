# CONSTITUTION.md — закон студии «Студия данных»

Проверяемые правила вертикали `data_analytics`: каждое связано с детерминированной проверкой
в `scripts/validate.mjs` (V-xx) или `scripts/lint-slop.mjs` (B-xx). Правило без проверки — пожелание.

## Статьи

- **К-01. Воспроизводимость.** Каждая метрика получена запросом из analysis/queries.sql.
- **К-02. Формула.** У метрики явная формула: числитель, знаменатель, фильтры.
- **К-03. Период.** Указан период расчёта; без него метрика не имеет смысла.
- **К-04. Источник данных.** analysis/report.md называет источник данных и его срез.
- **К-05. Выводы.** Отчёт содержит раздел «Вывод» с решением, а не пересказом чисел.
- **К-06. Разделение.** Метрики — в metrics.json, текст — в report.md; данные не дублируются.

## Приёмка

1. Проект не сдаётся, пока `node scripts/validate.mjs projects/<имя>` не вернул `exit 0`.
2. `node scripts/lint-slop.mjs projects/<имя>` печатает `чисто:`.
3. Цикл принуждения: `node core/loop-engine/cli.mjs projects/<имя> --studio-root verticals/data_analytics`.
