# SKILL-INDEX — приёмы студии «Студия данных»

Реестр приёмов вертикали `data_analytics` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `metric-report` | Собирает разбор: запросы, метрики с формулами, выводы и источник данных. | Определить период → Написать SQL-запросы → Посчитать метрики с формулами → Сформулировать выводы → Указать источник |
| `sql-audit` | Приём студии «Студия данных»: sql-audit. | — |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
