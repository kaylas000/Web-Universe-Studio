# CONSTITUTION.md — закон студии «Образовательная студия»

Проверяемые правила вертикали `education`: каждое связано с детерминированной проверкой
в `scripts/validate.mjs` (V-xx) или `scripts/lint-slop.mjs` (B-xx). Правило без проверки — пожелание.

## Статьи

- **К-01. Цели обучения.** Программа курса перечисляет измеримые цели обучения.
- **К-02. Три блока урока.** Урок содержит блоки «Теория», «Практика» и «Проверка».
- **К-03. Практика.** У каждого блока теории есть задание, которое ученик делает руками.
- **К-04. Проверка.** quiz.json содержит не менее трёх вопросов с вариантами ответа.
- **К-05. Источники.** course/SOURCES.md называет материалы, на которых построен урок.
- **К-06. Объём.** Урок достаточен, чтобы ученик прошёл его без дополнительного текста.

## Приёмка

1. Проект не сдаётся, пока `node scripts/validate.mjs projects/<имя>` не вернул `exit 0`.
2. `node scripts/lint-slop.mjs projects/<имя>` печатает `чисто:`.
3. Цикл принуждения: `node core/loop-engine/cli.mjs projects/<имя> --studio-root verticals/education`.
