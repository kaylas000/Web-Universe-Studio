# SKILL-INDEX — приёмы студии «Образовательная студия»

Реестр приёмов вертикали `education` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `lesson-plan` | Собирает урок: цели, теория, практика, проверка и источники. | Сформулировать цели обучения → Изложить теорию → Дать практику → Собрать проверку → Указать источники |
| `quiz-builder` | Приём студии «Образовательная студия»: quiz-builder. | — |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
