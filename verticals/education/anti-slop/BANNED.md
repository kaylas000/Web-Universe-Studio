# BANNED.md — анти-слоп студии «Образовательная студия»

Клише и приёмы, запрещённые в артефактах. Каждый пункт ловится `scripts/lint-slop.mjs`.

| Код | Что | Почему запрещено |
| --- | --- | --- |
| B-01 | Тест без объяснения | тест без объяснения правильного ответа |
| B-02 | Неполный выбор | «выберите все варианты» без числа |
| B-03 | Цель вне Блума | цель обучения вне таксономии Блума |
| B-04 | Неадекватная лексика | неадекватная возрасту лексика |
| B-05 | Материал без практики | материал без практики |
| B-06 | Скачок сложности | скачок сложности > 1 уровень |
| B-07 | Копипаста | копипаста без источника |

**Методы машинизации:** B-01…B-03, B-05, B-07 — паттерны в `scripts/slop.json` (линетр
`lint-slop.mjs`); B-04 (неадекватная лексика) — `V-03` (возрастная адекватность);
B-06 (скачок сложности) — `V-02` (прогрессия от простого к сложному).
