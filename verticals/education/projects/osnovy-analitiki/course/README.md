# Курс: Основы аналитики данных

## Цели обучения

Цели сформулированы по таксономии Блума:

1. **Знать** — перечислить типы метрик и их смысл.
2. **Понимать** — объяснить, почему метрика ценна только со знаменателем.
3. **Применять** — посчитать долю по данным из таблицы.
4. **Анализировать** — сравнить два периода и сформулировать вывод.

## Программа

- Урок 1. Первые шаги в аналитике.
- Урок 2. Срезы и сравнения.
- Урок 3. Выводы по данным.

## Прогрессия

Уроки идут от простого к сложному: знание метрик → применение расчёта доли → анализ сравнений.

Контраст текста не ниже 4,5:1; у схемы заполнен alt; к видео приложены субтитры.
