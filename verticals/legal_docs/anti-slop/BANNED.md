# BANNED.md — анти-слоп студии «Юридическая студия»

Запреты §10.2 ТЗ. Каждый пункт машинизирован в `scripts/slop.json` (pattern + code + message)
и ловится `scripts/lint-slop.mjs`; контрольные суммы реквизитов (B-08) проверяются кодом.

| Код | Что запрещено | Метод | Паттерн / критерий |
|---|---|---|---|
| B-01 | Шаблонные формулировки без реквизитов («именуемый в дальнейшем») | grep | `именуем(?:ый\|ая\|ое)\s+в\s+дальнейшем` |
| B-02 | Ссылка на НПА без редакции («в соответствии с действующим законодательством», статья без «ред. от») | grep | `в\s+соответствии\s+с\s+действующим\s+законодательством \| ст.\?\s*\d+\s+ГК\s+РФ(?!…ред\.)` |
| B-03 | «Прочие условия определяются сторонами» без раскрытия | grep | `прочие\s+условия\s+определяются\s+сторонами \| иные\s+условия\s+определяются\s+сторонами` |
| B-04 | Противоречие пунктов (пункты отменяют друг друга) | grep + линтер нумерации | `в\s+противоречии\s+с\s+пункт \| пункт\s+N\.M\s+отменяет`; дубли нумерации — V-04 |
| B-05 | ПДн без основания обработки | grep | `персональн…данн(?!… 152-ФЗ/основание/согласие)` |
| B-06 | Отсутствие порядка споров | grep | негативные формулировки: `претензии\s+не\s+принимаются \| споры\s+не\s+рассматриваются`; отсутствие раздела — V-08 |
| B-07 | Неактуальная форма (дата в прошлом) | grep | `дата\s+договора\|составлен(?:о)?[:：]?(19\d{2}\|20(?:0\d\|1\d\|2[0-5]))` |
| B-08 | Непроверенные контрольные суммы реквизитов | скрипт | любой ИНН/ОГРН/ОГРНИП в тексте, не прошедший контрольную сумму (isValidInn/isValidOgrn) |

**Напоминание:** линтер ловит точные паттерны. Отсутствие раздела (порядок споров, раздел
«Стороны») ловят валидаторы V-08/V-01, а не BANNED: запрет — это негативная формулировка,
требование — статья CONSTITUTION.
