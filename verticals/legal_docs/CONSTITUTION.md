# CONSTITUTION.md — закон студии «Юридическая студия»

Проверяемые правила вертикали `legal_docs`: каждое связано с детерминированной проверкой
в `scripts/validate.mjs` (V-xx) или `scripts/lint-slop.mjs` (B-xx). Правило без проверки — пожелание.

## Статьи

- **К-01. Предмет и стороны.** Договор содержит разделы «Предмет» и «Стороны» с полными реквизитами.
- **К-02. Нумерация.** Пункты нумеруются иерархически: 1.1, 1.2, …; ссылка на пункт однозначна.
- **К-03. Ответственность.** Раздел «Ответственность» фиксирует конкретные санкции, а не общие слова.
- **К-04. Применимое право.** Указано применимое право; при спорах — конкретная подсудность.
- **К-05. Источник норм.** Норма, на которую опирается документ, записана в docs/SOURCES.md с реквизитами акта.
- **К-06. Резюме для клиента.** docs/README.md объясняет риски и обязательства человеческим языком.

## Приёмка

1. Проект не сдаётся, пока `node scripts/validate.mjs projects/<имя>` не вернул `exit 0`.
2. `node scripts/lint-slop.mjs projects/<имя>` печатает `чисто:`.
3. Цикл принуждения: `node core/loop-engine/cli.mjs projects/<имя> --studio-root verticals/legal_docs`.
