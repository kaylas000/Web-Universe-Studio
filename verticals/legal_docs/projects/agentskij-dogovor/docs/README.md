# Резюме агентского договора

Принципал поручает Агенту поиск клиентов и заключение договоров оказания услуг. Перечень Поручений — в Приложении № 1.

## Что важно знать

- Просрочка выплаты вознаграждения: неустойка 0,1 % в день.
- Агент отчитывается о выполнении Поручений ежемесячно.
- Споры разбирает Арбитражный суд города Москвы (после претензии).
