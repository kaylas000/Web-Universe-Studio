# SKILL-INDEX — приёмы студии «Юридическая студия»

Реестр приёмов вертикали `legal_docs` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `contract-draft` | Собирает договор из обязательных разделов с нумерацией пунктов и реквизитами сторон. | Определить предмет и стороны → Заполнить обязательные разделы → Сверить нумерацию и реквизиты → Проверить анти-слоп студии |
| `legal-review` | Ревью документа по чек-листу: стороны, предмет, цена, срок, ответственность, применимое право (G4, HITL). | Разобрать бриф → Собрать артефакт по закону студии → Отдать на приёмку → Провести ревью по чек-листу |
| `requisites` | Проверяет реквизиты по контрольным суммам: ИНН (10/12) и ОГРН/ОГРНИП (13/15) через isValidInn/isValidOgrn; сверяет разделы «Стороны» и «Реквизиты». | Собрать ИНН/ОГРН из текста → Проверить ИНН по контрольной сумме → Проверить ОГРН по контрольной сумме → Сверить разделы «Стороны»/«Реквизиты» → Зафиксировать невалидные номера |
| `dispute-clause` | Собирает блок «Ответственность и споры» и «Изменение и расторжение»: неустойка и убытки, претензионный порядок со сроком, суд, порядок изменения/расторжения. | Определить ответственность → Описать претензионный порядок → Указать подсудность → Описать изменение/расторжение → Проверить непротиворечивость пунктов |
| `pdn-compliance` | Проверяет обработку ПДн по 152-ФЗ: цели, срок, согласие; не допускает обработку без основания (B-05). | Найти ПДн в тексте → Указать цели → Указать срок → Описать согласие и его отзыв → Сослаться на 152-ФЗ |
| `versioning` | Оформляет версию документа (дата, место, номер редакции) и сноски на НПА с редакцией/датой в SOURCES.md. | Указать дату/место/редакцию → Проверить актуальность формы → Собрать сноски на НПА → Указать редакцию/дату → Сверить акты из текста со сносками |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
