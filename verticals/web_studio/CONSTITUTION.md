Ошибки ловятся на самом дешёвом слое: IDE → pre-commit → CI → runtime. PR не мержится без зелёного CI, секреты и битые ссылки блокируют гейт.

Проверка: qa fortress + ci-гейты · метод: скрипт

## К-16
Маркетинговая воронка и оффер проектируются до верстки: проект содержит MARKETING.md с UVP, JTBD и картой CTA. Каждая кнопка содержит атрибуты аналитики `data-analytics-event`.

Проверка: lint-marketing.mjs (M-01, M-02) · метод: скрипт

## К-17
Редполитика и чистый копирайтинг: запрещены маркетинговые штампы (B-17) и бессодержательные CTA (B-18). Текст проходит типографирование (неразрывные пробелы, тире, кавычки) без висячих предлогов (B-23).

Проверка: lint-copy.mjs + typographer.mjs · метод: скрипт

## К-18
Продуктовая полнота UX и доступность: все интерактивные компоненты имеют 5 состояний (Ideal, Empty, Loading, Partial, Error). Контрастность текста не ниже 4.5:1 (WCAG AA).

Проверка: A11yContrastValidator + lint-contrast · метод: скрипт

## К-19
Программируемое кодовое видео должно быть детерминированным (Time Virtualization), использовать зарегистрированные рецепты движения (К-05) и поддерживать режим `prefers-reduced-motion`.

Проверка: lint-video-engine.mjs · метод: скрипт

## К-20
Senior-архитектура графики и адаптивности: цвета задаются в OKLCH (CSS Color Level 5) с поддержкой каскадных слоев `@layer`, компоненты адаптируются через Container Queries (`cqw`), а ресурсы контролируются бюджетом `Q-10` и SRI-хешированием sha384.

Проверка: V-16 Senior-аудит · метод: скрипт

## К-21
Закон исполняется циклом, а не памятью агента: итерации «сборка → ворота» прогоняются универсальным циклом (core/loop-engine/), который собирает контекст из архива, исполняет валидаторы и возвращает коды нарушений обратно в задачу. Проект не сдаётся без exit 0 цикла и сохранённого evidence.

Проверка: workspace/loop-result.json · exit 0 · метод: цикл

## К-22
SEO-гигиена страниц: title 50–60 знаков, description 120–158, canonical и og:url без .html, og:image абсолютным URL, тип Schema.org (JSON-LD), ровно один H1, контент ≥ 300 слов. Прокси-покрытие — site/*.html (вложенные lp/ и интерактив — на тире).

Проверка: seo-audit.mjs (V-18) · метод: скрипт

## К-23
Типографические минимумы: базовый кегль html/body — 16px (или явный ≥ 16px), интерлиньяж body ≥ 1.4, контентные теги (p/li/td/th/label/button/a) ≥ 14px. Шапки таблиц (th) и декоративные псевдо-подписи могут быть мельче (≥ 11px). Мелкие кикеры-классы (.meta/.label и т.п.) — допустимый дизайн.

Проверка: lint-typography.mjs (V-19) · метод: скрипт

## К-24
Перфоманс-бюджеты: у каждого `<img>` — атрибуты width и height (анти-CLS), за исключением первого экрана — loading="lazy"; внешние шрифты — @font-face с font-display: swap либо Google Fonts URL с display=swap; document.write() запрещён.

Проверка: lint-performance.mjs (V-20) · метод: скрипт

## К-25
Эвристики юзабилити NN/g (детерминированное ядро): H2 — `<html lang="…">`; H3 — якорная навигация `href="#…"` (переход внутри страницы); H4 — единая дизайн-система (`:root` + CSS-переменные `--*`); H6 — распознавание: нет пустых `<a></a>` и у каждого `<img>` есть `alt`; H10 — помощь: канал связи `tel:`/`mailto:`/форма. Полная карта 10 эвристик — `HEURISTICS.md`; качественные пункты — артдиректор на G4.

Проверка: lint-heuristics.mjs (V-21) · метод: скрипт
