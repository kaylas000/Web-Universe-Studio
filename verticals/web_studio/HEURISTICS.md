# HEURISTICS.md — карта эвристик юзабилити NN/g (К-25)

Источник: Jakob Nielsen, «10 Usability Heuristics for User Interface Design»
(NN/g, nngroup.com, ред. 2024) — `references/usability/REF-20.meta.yaml` (REF-20).
Эвристики — каркас приёмки: детерминированное ядро прогоняет
`node scripts/lint-heuristics.mjs projects/<имя>` (V-21), качественные пункты
проверяет артдиректор на G4.

## Карта 10 эвристик → ворота цеха

| # | Эвристика NN/g | Что значит для лендинга | Где проверяется |
| --- | --- | --- | --- |
| H1 | Видимость системного статуса | Живой статус форм (`aria-live`) — формы пока «вне этапа» | Будущий V-xx по формам; lint-copy |
| H2 | Соответствие системы реальному миру | `<html lang="ru">`, контент на языке пользователя | **V-21** (`lint-heuristics`: lang) |
| H3 | Свобода и контроль | Якорная навигация `href="#…"`, никаких ловушек | **V-21** (`lint-heuristics`: якоря) |
| H4 | Консистентность и стандарты | Одна дизайн-система: токены `:root { --* }` без разнобоя | **V-21** (`lint-heuristics`: токены) |
| H5 | Предотвращение ошибок | Нет форм — нет фатальных ошибок; микрокопи ошибок | lint-copy, БANNED (анти-слоп) |
| H6 | Распознавание, а не припоминание | Ссылки с текстом, у `<img>` непустой `alt` | **V-21** (`lint-heuristics`: alt/подписи) |
| H7 | Гибкость и эффективность | `:focus-visible`, клавиатурная навигация | lint-slop/focus, contrast-states |
| H8 | Эстетика и минимализм | Один акцент, паузы, токены — ни одной случайной детали | REF-19, lint-typography, motion |
| H9 | Восстановление после ошибок | 404.html, понятные сообщения | К-22 (SEO: 404), lint-copy |
| H10 | Справка и помощь | Канал связи: `tel:`/`mailto:`/форма | **V-21** (`lint-heuristics`: контакт) |

## Как закрывать

1. `node scripts/lint-heuristics.mjs projects/<имя>` → `Эвристики NN/g в норме` (exit 0).
2. `node scripts/validate.mjs projects/<имя>` — V-21 обязан быть OK.
3. Возврат — точечная правка по пунктам из feedback (К-10), а не перезапуск страницы.

Приём, который закрепляет эту карту: `skills/usability-heuristics/` (SK-20).
