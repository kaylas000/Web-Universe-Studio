# Быстрый сбор данных (одной командой)

## ВК (посты + фото) — id793867715
У VK API нет публичного экспорта стенки без токена. Есть 2 варианта, оба однократные:

Вариант 1. Архив VK (самый простой, без токенов, собирает всё)
— Зайди в VK → Настройки → Память и загрузка данных → Заказать архив
— Выбери «Стена» (и фото при желании)
— Получишь ссылку на ZIP (час-два). Скачай ZIP, положи в `проекты/vk_archive.zip`
— Я его распарсю и выгружу всё в `данные/vk_wall_parsed.json` + фото отдельно

Вариант 2. Токен (1 минута) — даёшь токен, я выгружаю мгновенно одной командой.

Когда положишь архив/токен — скажи, разберу сразу.
