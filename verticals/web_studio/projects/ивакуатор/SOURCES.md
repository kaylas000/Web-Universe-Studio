Кривые — motion/easing-curves.json (ceh-brake, ceh-drag, ceh-snap, ceh-coast, ceh-drive). Браузерные дефолты
запрещены (К-05). `prefers-reduced-motion` гасит кинематику (К-19). Лимит Q-01: три
рецепта на страницу, конфликтов `dont_combine_with` нет.

Анимация сцены — **не** четвёртый рецепт: папки рецепта у неё нет, Q-01 остаётся
тремя. Это bespoke-`@keyframes` (`sPull`, `sPullCable`, `sRoll`, `sWind`)
на самой иллюстрации в `site/styles.css`: такт 8000 мс, кривая `ceh-drag` из
`motion/easing-curves.json`, фазы 0–10 % (у земли) → 10–40 % (подтяжка) →
40–70 % (держим) → 70–100 % (отпускаем), 0 % и 100 % совпадают — цикл без шва. Трос и крюк машины идут по одной прямой,
поэтому видимый конец троса на всём такте сходится с крюком (расхождение ≤ 0.07 в
координатах `viewBox`). Гасится тем же `prefers-reduced-motion: reduce` — остаётся
статичное состояние «машина на платформе» (К-19). Геометрия сцены — руками по
`viewBox 0 0 720 340`, проверяется свипом `getBBox()` (SK-18).
