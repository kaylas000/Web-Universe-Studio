# G2 — Структура

## Цель
Каркас секций, где у каждой есть источник, и ни одной композиции из BANNED.

## Вход
G1 принят

## Чек-лист
1. Карта секций: имя + источник из архива (К-02)
   `@check section-sources`
2. ≥1 асимметричная композиция (Q-03)
   `@check asymmetry`
3. Нет композиций из BANNED (B-03, B-04…)
   `@check banned-subset`
4. Каждая секция отвечает на вопрос брифа
   `@check section-answers`
5. Порядок секций — драматургия, не шаблон

## Выходной артефакт
STRUCTURE.md

## Критерии отказа
Секции-шаблоны без привязки к источнику — возврат.
Прогон: `node cli/main.mjs gates G2 --studio web_studio --project <имя>`.
