# G1 — Направление

## Цель
Зафиксировать, ЧТО строим и из каких источников, до первой строки кода.

## Вход
Бриф + SEED.md (выдача roulette.mjs)

## Чек-лист
1. ≥3 референсов из references/ с дословными цитатами takeaway (V-01, К-01)
   `@check refs-takeaway min=3`
2. Палитра ≥3 цветов, собрана из палитр референсов, вне AI-диапазона, отпечаток уникален (К-14, Q-07, V-23)
   `@check palette min=3 ai=220-260 ai-max=0 accents=2`
3. Пара шрифтов из PAIRS.md с ролями display/body (К-07, Q-06, B-08)
   `@check font-pair from=assets/fonts/PAIRS.md`
4. Характер движения: 1–3 рецепта-кандидата из motion/ (К-06, Q-01)
   `@check motion-recipes min=1 max=3`
5. Раздел «ЧЕМ ЭТО НЕ» — ≥2 антиреференса с признаками запрета
   `@check anti-refs min=2`
6. Оси SEED отражены в тексте направления (V-07)
   `@check seed-axes`
7. Нет обтекаемых формулировок «современно», «стильно», «чисто» без приёмов
   `@check veto-phrases words=современно,стильно,минималистично`

## Выходной артефакт
DIRECTION.md

## Критерии отказа
Обтекаемые формулировки «современно», «чисто», «стильно» без приёмов — возврат.
Прогон: `node cli/main.mjs gates G1 --studio web_studio --project <имя>`.
