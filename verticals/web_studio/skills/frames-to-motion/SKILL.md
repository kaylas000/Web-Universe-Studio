# SK-19: Кадры заказчика в бесшовную анимацию (Frames to Motion)

Заказчик присылает не концепт, а готовые кадры: один SVG со слоями «пусто → в процессе →
готово» и просьбу «сделать анимацию». Нарисовать заново нельзя (рисунок — его), анимировать
нужно так, чтобы каждый кадр в фазе совпадал с его файлом, цикл не имел шва, а ворота
остались зелёными. Отработано на PRJ-04 (ивакуатор): три кадра `hero.svg` →
`hero-truck/fork/car.svg`, композит с машиношкой совпал с кадром заказчика на IoU 0,9979.

## 1. Разбор исходника

- Найти корневые слои и измерить `getBBox()` каждого **в браузере**, не по числом в атрибутах:
  координаты в файле Illustrator-экспорта расходятся с фактическим содержимым.
- Определить выравнивающий предмет — шасси, платформу, горизонталь, общую для всех кадров.
  Кадры сдвигаются `translate(dx, dy)` к нему; обычно один-два кадра лежат «смещёнными».
- Найти фоновой слой (сплошной залитый прямоугольник цветом бренда) и убрать его — фон
  сцены даёт страница, а цвет из рисунка ломает палитру (К-20, OKLCH только в CSS).
- Проверить самодостаточность ссылок каждой группы: `url(#…)`, `xlink:href`, `clipPath`,
  `use`, общие `defs`. Внешних ссылок быть не должно — иначе вырезка молча порвёт клипы.
  Если они есть, переносить `defs` внутрь вырезаемого куска, а не дублировать id.

## 2. Вырезка кадров

- Каждый кадр — отдельный файл с **одним общим `viewBox`** (объединение всех кадров),
  чтобы координаты в сцене были общими и кадры совпадали пиксель в пиксель.
- Сдвига кадра `translate` хватает, чтобы всё содержимое легло внутрь `viewBox`; проверка —
  `getBBox()` каждого файла равен ожидаемым координатам (допуск ±0,2 единицы).
- Подвижный элемент (машина, тележка) — отдельным кадром-файлом, даже если в исходнике он
  запечён в «готовом» кадре: только так он сможет ехать. Кадр «готово» при этом собирается
  из «пусто» + подвижный элемент, без его собственного дубля.
- Оригинал файла заказчика сохранить в `workspace/*.orig.svg`, не оставлять мёртвым
  файлом в `site/`.

## 3. Сборка сцены

- Порядок слоёв брать из собственного стекинга заказчика: если в «готовом» кадре машина
  запечена первой в группе, а в исходном файле слой машины лежит под траком — машина идёт
  **под** основным предметом, и композит будет равен его кадру.
- Управляющие слои — `<image href="файл.svg" x y width height>` (в `x/y/width/height`
  ставить координаты общего viewBox — тогда масштаб 1:1 и без леттербокса).
- Новые классы на всё новое (`h-*`) и новые `@keyframes` (`hXxx`): сцены соседних страниц
  делят правила `.s-*` — их нельзя трогать, или чужая сцена поедет.
- Внутри общего `<g>` — камера, поверх — подпись сцены (`s-label` и т.п. уже в CSS).

## 4. Таймлайн без шва

- Такт 8000 мс, **0 % = 100 % по каждому свойству** отдельно (transform, opacity), иначе
  цикл мигает на стыке.
- История читается фазами, например: 0–16 % приготовление (кроссфейд кадр 1 → 2),
  16–24 % камера отъезжает шире, 24–42 % объект въезжает, 46–60 % посадка с кроссфейдом
  обратно и сужением камеры, 60–76 % держим, 76–94 % разгрузка и выезд,
  94–100 % возврат камеры.
- Кадры перекрывает **кроссфейд двух слоёв** (нижний остаётся, верхний гаснет) — путь
  между кадрами не сморфить, только растворить; поэтому верхний слой анимируется зеркально
  нижнему.
- Подвижный элемент едет `translate()` между позами: из-за кадра → позиция кадра 2 → позиция
  на платформе (дельта = разница координат кадров) и обратно.
- Последняя фаза перед 100 % должна **заканчиваться плоско** (кривая с горизонтальным
  хвостом): скорость на границе цикла равна нулю, иначе стык дёргается.

## 5. Камера и инвариант земли

- Камера — `transform: translate(tx, ty) scale(s)` на общем `<g>`, обязательно
  `transform-box: view-box; transform-origin: 0 0` (иначе `scale` считается от центра
  `viewBox`, а не от нуля, и вся матриатика едет).
- Два состояния (крупный план / широкий) подбираются так: точка привязки (линия земли,
  центр предмета) должна попадать в одни и те же координаты сцены при обоих `s`:
  `ty = y_сцены − y_содержимого · s`. Тогда инвариант сохраняется и при интерполяции —
  земля «не дышит» ни на одном кадре, потому что линейная интерполяция двух состояний
  с общим инвариантом даёт тот же инвариант.
- Масштаб крупного плана держать ≥0,28 (содержимое читается на 385px-сцене), широкого —
  такой, чтобы весь объединённый `viewBox` влезал в 720 единиц с запасом на кромку.

## 6. Приёмка числами, не глазами

- Пробы кадра: `el.getAnimations()[0]` → `pause()` → `currentTime = t` на 5–7 точках
  (0, фазы, 100 %−1 мс) и читать `getComputedStyle().transform` — матрица обязана совпасть
  с ключевым значением до третьего знака.
- Шов: замер на 9999 мс против 0 мс — расхождение <0,001.
- **Попиксельное доказательство выравнивания**: скомпоновать «кадр 1 + подвижный элемент
  в позиции готово» и сравнить с «готовым» кадром заказчика: маски прорастрировать в канвас,
  IoU ≥0,99, средняя разница RGB ≈2–3/255. Это единственная проверка, которая ловит сдвиг
  выравнивания на пару единиц.
- Растеризация каждого файла (canvas, доля непрозрачных пикселей) доказывает, что контент
  вообще рисуется, а не только что XML валиден.
- `prefers-reduced-motion: reduce` → `animation: none` на новых классах; **база сцены =
  финальный кадр** (загруженное состояние), тогда статика — не пустой экран, а кадр 3.
- Q-01: у иллюстрации нет папки рецепта, отдельная строка в SOURCES.md — иначе это
  четвёртый рецепт (V-05). Кривые только `var(--curve-*)` из easing-curves.json (К-05),
  такт тот же, что у соседних иллюстраций.

## Ловушки метода

- **`getBoundingClientRect` на SVG врёт на ширину рамки**: `border` элемента попадает в
  прямоугольник, и выведенный из rect масштаб занижается на ~0,6 % (0,3 против 0,2981).
  Матрицу брать из `getComputedStyle().transform`, rect — только для грубых проверок.
- **Морозилка окружения.** В невидимом окне `currentTime` всех анимаций (включая
  унаследованные `sPull`, `grainShift`) стоит на 0 при `playState: running` — это не баг
  сцены. Проверять, замером унаследованной анимации на соседней странице.
- **Заморозка через `animation-delay` ненадёжна**: эффективное время считается от
  момента запуска анимации и плюсует «простой» страницы. Только `currentTime` объекта
  анимации.
- **Внешние `<image>` не грузятся в SVG, отрисованном через `<img>`**: для попиксельного
  сравнения вшивать содержимое файлов как `data:` URI.
