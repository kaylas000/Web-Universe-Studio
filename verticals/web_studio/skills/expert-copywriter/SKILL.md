# SK-22: Экспертный текст без следов ИИ

Текст цеха пишет человек для человека: он опирается на факты и единицы измерения (SK-13), а не на
«манеру» языковой модели. Экспертность — это конкретика и глагол; «манеру ИИ» надо снимать так же,
как слоп в вёрстке.

## Правила

1. **Глагол вместо связки.** «Представляет собой / является / играет важную роль» → действие:
   - Плохо: *«Компания является лидером рынка»*.
   - Хорошо: *«Компания делает 400 отгрузок в месяц»*.
2. **Число вместо абстракции.** «Много / быстро / удобно / качественно» → метрика с единицей и сроком.
3. **Ноль артефактов копипаста.** Никогда не оставлять следы чат-ботов: `oaicite`, `turn…search`,
   `utm_source=chatgpt.com`, `【…†…】`, `sandbox:/mnt/data/`, плейсхолдеры `INSERT_SOURCE_URL`,
   `URL_HERE`, `20XX-XX-XX`. Это жёсткий провал ворот (коды `A-xx`).
4. **Снять манеру ИИ.** Канцелярит и штампы-связки, faux-insight («по сути», «если копнуть глубже»),
   сервильность («надеюсь, это поможет»), дежурный оптимистичный финал — убрать.
5. **Живой ритм.** Разбивать предложения длиннее 45 слов; менять длину — абзац не должен быть
   метрономом из одинаковых фраз.
6. **Править удалением.** Не дописывать «голос» от себя — убирать лишнее и заменять абстракцию фактом.

## Проверка

Детерминированный линтер (общий движок `core/vertical-kit/copywriting.mjs`, правила — `scripts/copy.json`):

```bash
node scripts/lint-copy.mjs projects/<имя>   # ошибки A-xx гейтят; стиль — сводка «[lint-copy] …», балл 0-100
```

- `A-xx` — артефакты копипаста: блокируют приёмку (жёсткий гейт).
- `C-xx` / `N-xx` / `R-xx` — стиль и ритм: идут в балл и сводку, не блокируют (длинное тире и
  «не только… но и» — нормальная русская речь, а не запрет языка).
- Жанр текста задаётся в `scripts/copy.json` (`genre`): `marketing`, `expert`, `business`,
  `academic`, `legal`, `news` — часть стилевых правил в научной/юридической прозе смягчается.

Источник приёма: `references/` (REF, humanizer-ru — MIT). Отрицательный результат линтера — не «стиль
плохой», а список точечных правок по К-10.
