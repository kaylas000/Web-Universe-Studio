# SK-20: Эвристики юзабилити NN/g (Heuristics Checklist)

Десять эвристик Якоба Нильсена (nngroup.com) сворачиваются для статической страницы
в проверяемое ядро — его прогоняет `node scripts/lint-heuristics.mjs projects/<имя>` (V-21, К-25):

1. **H2 — Соответствие системы реальному миру**: `<html lang="ru">` (и любой контент — на языке пользователя).
2. **H3 — Свобода и контроль**: якорная навигация `href="#…"` — из любой секции можно перейти к нужной.
3. **H4 — Консистентность и стандарты**: одна дизайн-система на страницу — токены `:root { --*: … }` без разнобоя цветов/радиусов в селекторах.
4. **H6 — Распознавание, а не припоминание**: ссылки с текстом (не пустые `<a></a>`), у каждого `<img>` непустой `alt`.
5. **H10 — Справка и помощь**: на главной есть канал связи — телефон/почта/форма.

Остальные эвристики для лендинга закрываются другими воротами цеха:

- **H1 — Видимость статуса**: формы с живым статусом — `aria-live` (пока в «вне этапа»).
- **H5 — Предотвращение ошибок**: лендинг без форм; ошибочные сценарии — микрокопи (lint-copy).
- **H7 — Гибкость и эффективность**: `:focus-visible`, клавиатурная навигация (lint-slop/focus).
- **H8 — Эстетика и минимализм**: один акцент — токены и типографика (lint-typography, motion).
- **H9 — Восстановление после ошибок**: 404.html и понятные сообщения (SEO-аудит, К-22).
