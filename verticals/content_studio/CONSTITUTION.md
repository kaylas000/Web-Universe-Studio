# CONSTITUTION.md — закон студии «Контент-студия»

Полные статьи вертикали `content_studio` (§9 ТЗ). Проверка статьи — метод из ТЗ (графа «Проверка»):
детерминированный офлайн-набор `scripts/validate.mjs` (коды `V-xx`) реализует подмножество статей; остальное — приёмка человеком на G4 (REVIEW.md).

## Статьи

- **К-01. Уникальность.** Уникальность текста > 90 % (шингловый анализ). *Проверка:* lint-unique.mjs.
- **К-02. Плотность ключа.** Плотность ключевого слова 1–3 % без переспама. *Проверка:* счётчик вхождений.
- **К-03. Читаемость.** Читаемость: адаптированный Flesch-Kincaid ≥ 60. *Проверка:* lint-readability.mjs.
- **К-04. Структура.** Структура: ровно один H1, корректная иерархия H2/H3. *Проверка:* HTML/MD-линтер.
- **К-05. Мета.** Мета: title 50–60, description 120–158 символов. *Проверка:* seo-gate.
- **К-06. Ссылки.** ≥2 внутренних ссылок + авторитетные внешние. *Проверка:* линк-аудит.
- **К-07. Нет штампов и воды.** Нет штампов и воды (B-xx). *Проверка:* lint-copy.
- **К-08. Факты с источником.** Факты и цифры снабжены источником/сноской. *Проверка:* lint-facts.mjs.
- **К-09. Tone of voice.** Tone of voice из брифа соблюдён. *Проверка:* маркеры брифа (V-09).
- **К-10. Атрибуция.** Атрибуция/авторство (E-E-A-T) указано. *Проверка:* метаданные.
- **К-11. Изображения с alt.** Изображения с alt и оптимизированным форматом. *Проверка:* линтер ассетов.
- **К-12. JSON-LD.** JSON-LD соответствует типу контента (Article/Product/FAQ). *Проверка:* schema-валидатор.
- **К-13. Редполитика.** Редполитика: типографика, тире, кавычки, без висячих предлогов. *Проверка:* typographer.mjs.
- **К-14. CTA с аналитикой.** CTA имеют data-analytics-event. *Проверка:* lint-marketing.
- **К-15. Нет AI-паттернов.** Нет однообразных AI-паттернов («важно отметить», «в современном мире»). *Проверка:* lint-copy AI-профиль.

**Гейты:** G1 Бриф/семантика → G2 Структура/ключи → G3 Текст → G4 Редполитика.

## Приёмка

1. Проект не сдаётся, пока `node scripts/validate.mjs projects/<имя>` не вернул `exit 0`.
2. `node scripts/lint-slop.mjs projects/<имя>` печатает `чисто:`.
3. Цикл принуждения: `node core/loop-engine/cli.mjs projects/<имя> --studio-root verticals/content_studio`.
