# CONSTITUTION.md — закон студии «Контент-студия»

Проверяемые правила вертикали `content_studio`: каждое связано с детерминированной проверкой
в `scripts/validate.mjs` (V-xx) или `scripts/lint-slop.mjs` (B-xx). Правило без проверки — пожелание.

## Статьи

- **К-01. Один заголовок.** Пост начинается с одного H1; дубли H1 запрещены.
- **К-02. Лид.** Первый абзац объясняет пользу поста в двух-трёх предложениях.
- **К-03. Структура.** Не менее двух подзаголовков H2 разбивают текст на смысловые блоки.
- **К-04. Метаданные.** content/meta.json содержит title, description и tags.
- **К-05. Источники.** Каждый факт с числом или нормой подтверждён в content/SOURCES.md.
- **К-06. Призыв.** Пост заканчивается призывом к действию.

## Приёмка

1. Проект не сдаётся, пока `node scripts/validate.mjs projects/<имя>` не вернул `exit 0`.
2. `node scripts/lint-slop.mjs projects/<имя>` печатает `чисто:`.
3. Цикл принуждения: `node core/loop-engine/cli.mjs projects/<имя> --studio-root verticals/content_studio`.
