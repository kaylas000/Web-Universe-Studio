# tools студии «Контент-студия»

Каталог под вспомогательные утилиты студии. Приёмка студии живёт в `scripts/`.

## typographer.mjs

Приводит текст к редполитике студии (К-13): типографские кавычки «ёлочки»,
длинное тире —, неразрывные пробелы после предлогов (убирает висячие предлоги),
сохраняет ё и по опции доставляет её в безопасных словоформах.

```bash
node tools/typographer.mjs projects/<имя>/content/post.md
node tools/typographer.mjs draft.md --yo --write
```

- `--yo` — ёфикация безопасных словоформ (ещё, берёза, ковёр);
- `--write` — записать исправленный текст обратно в файл.

Исправленный текст уходит в stdout (можно перенаправить в файл), счётчик замен —
в stderr: `замен: N (кавычки: a · тире: b · неразрывные пробелы: c · ё: d)`.
HTML-теги (`<button data-analytics-event="cta">`), fenced-код и инлайн-`код` не
трогает: кавычки атрибутов и кода остаются как есть.

- exit 0 — ок; 1 — файл не прочитан/не записан; 2 — нет аргумента.

ESM-API: `typograph(text, { yo })` → `{ text, counts }`, словари `PREPOSITIONS` и
`YO_WORDS`. Студия использует ту же редполитику декларативно: `scripts/validate.mjs`
(V-13) и `scripts/lint-quotas.mjs` (Q-05/Q-06) читают те же правила.
