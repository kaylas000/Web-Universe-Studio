# SKILL-INDEX — приёмы студии «Контент-студия»

Реестр приёмов вертикали `content_studio` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `longform-post` | Собирает пост: лид, два и более подзаголовка, метаданные, источники, призыв к действию. | Сформулировать лид → Развернуть подзаголовками → Собрать метаданные и источники → Поставить призыв к действию → Проверить анти-слоп |
| `copy-edit` | Приём студии «Контент-студия»: copy-edit. | — |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
