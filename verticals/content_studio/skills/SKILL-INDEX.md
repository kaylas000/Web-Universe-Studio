# SKILL-INDEX — приёмы студии «Контент-студия»

Реестр приёмов вертикали `content_studio` (§11 ТЗ). Один приём = директория
`skills/<id>/`: `skill.yaml` (метаданные) + `templates/*.j2` (шаблоны ролей) +
`hooks/*.mjs` (ESM-крючки `pre_execute`/`post_execute`).

| Приём | Назначение | Шаги |
|---|---|---|
| `longform-post` | Собирает пост: лид, два и более подзаголовка, метаданные, источники, призыв к действию. | Сформулировать лид → Развернуть подзаголовками → Собрать метаданные и источники → Поставить призыв к действию → Проверить анти-слоп |
| `copy-edit` | Приём студии «Контент-студия»: copy-edit. | — |
| `seo-meta` | Собирает мету по К-05 (title 50–60, description 120–158) и К-12 (JSON-LD по типу контента). | Собрать семантику → Написать title → Написать description → Собрать JSON-LD → Проверить мету |
| `link-audit` | Проверяет ссылочный граф по К-06: ≥2 внутренних ссылок и авторитетные внешние. | Собрать ссылки → Проверить внутренние → Проверить внешние → Проверить якоря → Зафиксировать нарушения |
| `typography` | Приводит текст к редполитике К-13: ёлочки «», тире —, неразрывные пробелы, без висячих предлогов. | Проверить кавычки → Заменить дефис-минус → Вставить неразрывные пробелы → Убрать висячие предлоги → Прогнать typographer.mjs |
| `cta-analytics` | Проверяет CTA по К-14 (data-analytics-event) и изображения по К-11 (alt). | Найти CTA → Проверить событие аналитики → Проверить alt → Сверить с целью брифа → Зафиксировать нарушения |

Загрузчик — `core/loop-engine/skills.mjs`; рендер шаблонов — `core/loop-engine/template.mjs`.
