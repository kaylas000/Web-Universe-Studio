# Опросник

Telegram Mini App без сборщика: разметка, скрипт и стиль. Один экран — три вопроса,
черновик сохраняется в CloudStorage, ответы уходят боту через `sendData` (К-13, К-07).

## Платформа

Telegram WebApp SDK (MainButton, BackButton, HapticFeedback, CloudStorage, Telegram Payments).

## Запуск

Откройте app/index.html в браузере; в Telegram — через бота.
