```text
1. Заказчик: сеть эвакуаторов «Ивакуатор» (Химки и Москва)
2. Задача (одним предложением): дать водителю в беде за один тап вызвать эвакуатор и видеть, когда он приедет.
3. Артефакт (app/): VK Mini App + Telegram Mini App (кросс-платформенный): экран выбора услуги → форма адреса → отслеживание эвакуатора → оплата.
4. Обязательные требования (законы студии К-xx):
   - К-01: адаптация 320/375/420
   - К-02: один экран — одна задача (нативные кнопки SDK)
   - К-03: var(--tg-theme-*) / VK Bridge theme
   - К-05: env(safe-area-inset-bottom)
   - К-06: viewportChanged
   - К-07: openInvoice/sendData (Telegram Payments)
   - К-08: бандл < 300KB gzip
   - К-14: без alert/confirm/prompt
   - К-15: HMAC-SHA256 проверка initData на сервере
   - К-18: без утечек памяти (clearInterval/removeEventListener)
   - К-20: один primary CTA (MainButton)
   - К-21: контраст ≥ 4.5:1 (WCAG AA)
   - К-22: 10 эвристик NN/g
   - К-23: конкретика цифрами (цена, время)
   - К-24: prefers-reduced-motion
5. Анти-требования (чего быть не должно):
   - Несколько экранов-простыней без нативных кнопок
   - Модалки при загрузке
   - window.location.href для переходов
   - Следы ИИ в тексте (A-xx коды)
   - Квоты сверх Q-01…Q-05
6. Критерий приёмки: validate.mjs → «ИТОГ: N/N · exit 0», lint-slop → «чисто:», lint-copy → 0 ошибок, цикл loop-engine → exit 0.
```

Бриф без пунктов 2–3 не запускает цикл: агент возвращает его на уточнение.
