# BANNED.md — анти-слоп студии «Студия мини-приложений»

Клише и приёмы, запрещённые в артефактах. Каждый пункт ловится `scripts/lint-slop.mjs`.

| Код | Что | Почему запрещено |
| --- | --- | --- |
| B-01 | Только hover | `:hover` как единственный способ взаимодействия (на тач нет hover) — regex `:hover` без `:active` |
| B-02 | Жёсткий 100vh | жёсткий `height: 100vh` (перекрывается клавиатурой/шапкой) — regex без `env(safe-area-inset)` |
| B-03 | Навигация href | навигация через `window.location.href` (закроет Mini App) — regex |
| B-04 | Кастомный скроллбар | кастомные скроллбары (`::-webkit-scrollbar`) — ломают iOS momentum — regex |
| B-05 | Блокирующие модалки | блокирующие модалки при загрузке (< 500ms) — DOMContentLoaded + modal.show |
| B-06 | Штампы без фактов | «индивидуальный подход», «высокое качество», «инновационный», «динамично развивающийся», «лидер рынка» без цифр — regex |
| B-07 | «Нажмите сюда» | CTA без действия («нажмите сюда/здесь/тут») — кнопка обязана называть результат — regex |
| B-08 | Ошибка без решения | текст ошибки без следующего шага (нет «повторите/попробуйте/проверьте/начните») — regex с negative lookahead |
| B-09 | Пустота без подсказки | пустое состояние («пока пусто», «нет данных/записей/заказов») без «начните/добавьте/выберите» — regex |
